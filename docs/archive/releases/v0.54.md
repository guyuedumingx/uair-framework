## Production bugs found and fixed during v0.54

### Reliable queue stale worker projection

SQLite queue retry/reclaim previously did:

```text
assigned_worker_id = NULL
```

without clearing:

```text
job.workerId
```

Shared worker load reconciliation could therefore count an unassigned job
against the old worker forever.

Observed consequence:

```text
worker capacity appears full
unassigned resume jobs cannot be routed
durable executions remain suspended
```

Fix:

```text
durable assigned worker and serialized routing projection
are cleared together
```

The chaos recovery drain also now rebuilds disposable queue delivery intents
from durable `resume_requested` history, matching RuntimeEngine recovery
semantics.

### PostgreSQL missing Runtime Storage

support.

v0.54 adds:
