# UAIR v0.58 Release Status

## Decision

```text
Public/source alpha release candidate:
READY AFTER EXTERNAL ENVIRONMENT GATES

Production-grade 1.0:
NOT YET
```

v0.58 is a Release Candidate documentation/DX hardening release. No new Runtime
Core primitive was introduced.

## What changed

The repository now has one explicit documentation path:

```text
README
→ docs/README.md
→ Quick Start / Mental Model / Core Concepts
→ task-specific guides
→ production or maintainer docs
```

Maintainers now have dedicated guidance for:

```text
architecture boundaries
durable contracts
adding adapters
adding storage
release process
```

Coding Agents now have repository-level instructions:

```text
AGENTS.md
AI_AUTHORING_GUIDE.md
```

Contributors have:

```text
CONTRIBUTING.md
```

## Acceptance contracts

Two release-facing black-box acceptance specifications are now included:

```text
Fresh Developer Acceptance
Fresh AI Acceptance
```

They explicitly test whether a new user/model can discover that:

```text
pure logic stays ordinary TypeScript
Component is a durable external boundary
Workflow is durable orchestration
Interaction/Suspension handles later external input
approval/OA is not Core
security/tenant is optional host policy
stable IDs are semantic and minimal
```

The acceptance specifications and documentation structure are automatically
checked, but **an independent human/model has not been executed inside this
build environment**. That remains external release evidence.

## Environment-dependent release evidence still required

Mac/CI checklist:

```text

actual previous-binary + candidate rolling upgrade
real authenticated Codex Builder

live LangGraph + durable checkpointer
live Anthropic/Claude integration
```

See `../../release/mac-validation.md`.

## Release recommendation

If the real PostgreSQL and release-environment P0 gates pass, publish as a
clearly labeled `0.x` alpha rather than continuing to add Core concepts.

Use third-party issues/adapters/packages as the next source of design evidence.
Do not call the project production-grade 1.0 until the remaining P0 and required
1.0 evidence in `../../operations/production-readiness.md` are complete.
