## P0 bug fixed

`migrateExecutionHistory()` previously accepted an Execution whose
`historySchemaVersion` was newer than the Runtime's supported schema.

That is unsafe for rollback/rolling upgrades.

v0.55 adds:

```text
HistorySchemaTooNewError
```

and fails closed when:

```text
found History schema > supported History schema
```

This now matches Runtime storage schema behavior.
