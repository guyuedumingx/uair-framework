# Support

UAIR is currently an alpha project.

Use:

- GitHub Discussions (if enabled) for usage/design questions;
- GitHub Issues for reproducible bugs and accepted feature requests;
- private security reporting for vulnerabilities.

Before filing a bug, run the relevant local release checks documented in
`docs/release/checklist.md` and include Node.js version, OS, UAIR package
versions, and a minimal reproduction.
